# Contributing to Haven

Please read the full guide in **[docs/contributing.md](docs/contributing.md)** (also published at [zyvorai.github.io/haven/contributing/](https://zyvorai.github.io/haven/contributing/)).

Also see:

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Security Policy](SECURITY.md)
- [Maintainers](MAINTAINERS)

Commits must include a DCO `Signed-off-by` line (`git commit -s`).

Quick start:

```bash
make dev && make wait && make doctor
make ui-install && make ui-dev
make docs-serve    # preview documentation
```
