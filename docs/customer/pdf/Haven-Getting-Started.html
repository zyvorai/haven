Operate tips

  1. Always confirm Connected on Deck or Settings before realm work.
  2. Create realms in Realm Studio; mint OIDC clients under Clients or realm detail.
  3. Persist password changes in secrets before pod restart — see Passwords.
  4. Never paste lab IPs into runbooks — use <host>.

Verify a fresh lab

  1. Deploy: ./scripts/deploy-remote.sh <host> <user> (Getting Started).
  2. Sign in (demo / demo or admin).
  3. Command Deck — Connected + Ready (or external Postgres noted).
  4. Settings — green Connected banner.
  5. Atlas — path hops look healthy.

Create a realm and invite a user

  1. Realm Studio → + Create realm.
  2. Open Realm detail → + Invite user.
  3. Set password when prompted; verify login against that realm’s account console if needed.

Mint an OIDC client

  1. Clients (or realm detail Clients tab).
  2. Create confidential/public client with redirect URI for your app.
  3. Copy client secret once; paste into the relying party.
  4. Optional: regenerate secret later with confirm.

Deploy a new identity plane

  1. Deploy wizard → Review & Deploy.
  2. Watch Planes and Deck reconcile timeline until Ready.
